# Machine Learning Streamlit App

## Project Overview
This project is an interactive machine learning application built using Python and Streamlit. Users can upload their own dataset, select a supervised learning model, adjust hyperparameters, and evaluate model performance.

The goal of this project is to demonstrate applied machine learning concepts and create an intuitive interface for experimentation.

---

## Features
- Upload custom CSV datasets
- Select target variable
- Choose machine learning model:
  - Logistic Regression
  - K-Nearest Neighbors (KNN)
  - Decision Tree
- Adjust hyperparameters using sliders
- View model performance (accuracy)
