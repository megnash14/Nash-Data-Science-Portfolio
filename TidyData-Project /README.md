# Tidy Data & Statistical Analysis
This project demonstrates advanced data cleaning, reshaping, and exploratory statistical analysis. It focuses on transforming "messy" datasets into "tidy" formats to uncover insights into global trends and data distributions using Python.

![Project Screenshot](assets/screenshot.png)

### TLDR:
Data Wrangling and Statistical Analysis project built with **Pandas** and **Seaborn**. It automates the cleaning of raw data and provides deep-dive visualizations into dataset correlations and distributions.

## Description:
* This Tidy Data Analysis project is a comprehensive notebook that explores the principles of data tidying—ensuring each variable is a column, each observation is a row, and each type of observational unit is a table.
* The analysis transforms raw, unorganized data into a structured format, enabling accurate statistical modeling and clearer visualizations.
* It includes complex data pivots, handling of missing values, and the application of descriptive statistics to identify outliers and significant trends.
* By applying these techniques, the project illustrates how clean data is the essential foundation for any successful Machine Learning or Data Science initiative.

## Skills & Technologies Used:
* **Environment**
* **Jupyter Notebook** - Interactive Coding & Documentation
* **Data Cleaning & Wrangling**
* **Pandas** - Melding, Pivoting, Grouping, Handling Nulls
* **NumPy** - Vectorized Operations & Statistical Math
* **Visualization**
* **Seaborn**, **Matplotlib** - Heatmaps, Histograms, Boxplots
* **Statistical Analysis**
* **Descriptive Statistics** - Mean, Median, Variance, Correlation Matrices

## Technical Explanations:
* **Data Reshaping:** Utilizing `melt` and `pivot` to transform wide-format data into long-format data, which is required for modern visualization libraries.
* **Correlation Heatmaps:** Used to identify the strength of relationships between numerical variables, guiding future feature selection.
* **Handling Missingness:** Applying strategic imputation or removal of null data to maintain the integrity of statistical results.
